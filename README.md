Amazon UI Clone

A frontend website inspired by Amazon's e-commerce layout, built using HTML and CSS. This project recreates the visual structure of an online shopping platform, including the navigation bar, search section, promotional banner, product category cards, and footer.

Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Font Awesome Icons

Features

- Amazon-inspired navigation bar and search interface
- Product category cards with images
- Promotional hero section
- Multi-section footer
- Basic responsive styling for smaller screens

Purpose

Created as a learning project to practice HTML structure, CSS styling, Flexbox layouts, and responsive web design.
